## Systematic Error Patterns Identified

### 1. Missing Initial States in Place Files ⭐ CRITICAL ISSUE
**Pattern**: Place files systematically missing `(Open X)` initial states that are present in originals.

**Affected**: 9 place files
**Examples**:
- `KITCHEN_SCENE10_put_the_black_bowl_in_the_top_drawer_of_the_cabinet_place.bddl`
  - Missing: `(Open wooden_cabinet_1_top_region)`
- `KITCHEN_SCENE5_put_the_black_bowl_in_the_top_drawer_of_the_cabinet_place.bddl` 
  - Missing: `(Open white_cabinet_1_top_region)`

**Root Cause**: Generation script for place files does not copy over the Open states from the original files. This is critical because you cannot place objects in closed drawers/cabinets.

### 2. Wrong Objects in Place Files ⭐ CONFIRMED ISSUE
**Pattern**: Place files contain objects that should not be present (mentioned in user request).

**Affected**: 33 place files
**Specific Cases Found**:
- **Red cup in chocolate pudding files**: `LIVING_ROOM_SCENE6_put_the_chocolate_pudding_*_place.bddl` files contain `red_coffee_mug_1` but are missing `porcelain_mug_1`
- **Missing scene objects**: Many place files are missing objects that exist in the original complete scene

**Examples**:
- `LIVING_ROOM_SCENE6_put_the_red_mug_on_the_plate_place.bddl`
  - Missing: `porcelain_mug_1`, `chocolate_pudding_1`
- `KITCHEN_SCENE3_put_the_moka_pot_on_the_stove_place.bddl`
  - Missing: `chefmate_8_frypan_1`

### 3. Missing Fixtures in Pick Files ⭐ CRITICAL ISSUE
**Pattern**: Pick files missing fixtures that are referenced in their regions/goals.

**Affected**: 6 pick files (but pattern suggests broader issue)
**Examples**:
- `KITCHEN_SCENE7_put_the_white_bowl_on_the_plate_pick.bddl`
  - Missing fixture: `microwave_1`
  - But references `microwave_1` in regions
- Multiple files missing `flat_stove_1` fixture while referencing stove regions

**Root Cause**: Pick file generation script not including all fixtures that are referenced in the spatial relationships.

### 4. Missing Regions Referenced in Goals/Init
**Pattern**: Files missing region definitions that are referenced elsewhere.

**Affected**: 107 instances
**Examples**:
- Missing `plate_left_region` in multiple Living Room files
- Missing `flat_stove_init_region` in Kitchen files
- Missing `wooden_cabinet_init_region` in many files

## Detailed Breakdown by File Type

### Pick Files (suffix: `_pick.bddl`)
**Common Issues**:
- Missing fixtures that are spatially referenced
- Missing objects from the complete scene
- Missing regions needed for spatial relationships

**Pattern**: Pick files seem to be generated with minimal object sets, missing the broader scene context.

### Place Files (suffix: `_place.bddl`) 
**Common Issues**:
- **Critical**: Missing `(Open X)` initial states
- Wrong object sets (extra/missing objects)
- Missing fixtures and regions

**Pattern**: Place files appear to be generated by filtering from pick files but lose essential initial state information.

### Action Files (drawer/microwave open/close, stove on/off)
**Common Issues**:
- Missing scene objects that should be present
- Overly simplified object sets

## Generation Script Issues Identified

Based on the error patterns, the generation scripts appear to have these systematic problems:

### 1. Initial State Propagation Issue
```
PROBLEM: Place files don't inherit (Open X) states from originals
IMPACT: Cannot place objects in closed containers
FIX NEEDED: Copy all Open states from original to place files
```

### 2. Object Set Filtering Issue  
```
PROBLEM: Inconsistent object filtering between pick/place files
IMPACT: Wrong objects present, spatial references break
FIX NEEDED: Consistent object set determination logic
```

### 3. Fixture Reference Issue
```
PROBLEM: Fixtures removed but still referenced in regions/goals
IMPACT: Broken spatial relationships, undefined references
FIX NEEDED: Keep all fixtures that are spatially referenced
```

### 4. Region Dependency Issue
```
PROBLEM: Regions removed without checking dependencies
IMPACT: Goals/init states reference non-existent regions  
FIX NEEDED: Dependency analysis before region removal
```

## Most Critical Issues Requiring Immediate Fix

1. **Missing Open States in Place Files** - Breaks task execution
2. **Missing Fixtures with References** - Causes undefined reference errors
3. **Wrong Object Sets** - Breaks scene consistency
4. **Missing Referenced Regions** - Causes goal definition errors

## Recommendations

1. **Fix Generation Scripts**: Address the 4 systematic issues identified above
2. **Add Validation**: Implement checks for reference consistency 
3. **Test Suite**: Create validation suite to catch these patterns
4. **Incremental Fix**: Start with missing Open states as highest priority
